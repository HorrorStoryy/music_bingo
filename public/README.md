# 🎵 Музыкальное Лото

Мультиплеерная веб-игра "Музыкальное лото" с возможностью загрузки своей музыки и клипов.

## 🎮 Как играть

1. **Хост** создаёт комнату и загружает музыку (MP3, видео)
2. **Игроки** подключаются по коду комнаты или QR-коду на своих телефонах
3. Хост включает треки в случайном порядке
4. Игроки отмечают треки в своих карточках лото
5. Кто первый закроет все ячейки — **победил!** 🎉

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## 📱 Технологии

- **React** + **TypeScript** — UI
- **Tailwind CSS** — стили
- **PeerJS** — P2P связь между устройствами (WebRTC)
- **Framer Motion** — анимации
- **Vite** — сборка

## 🌐 Деплой на GitHub Pages

1. Создайте репозиторий на GitHub
2. Добавьте файл `.github/workflows/deploy.yml`
3. Настройте GitHub Pages → Source: GitHub Actions
4. Push в main — сайт автоматически задеплоится

## 📋 Структура

```
src/
├── App.tsx          — Роутинг
├── types.ts         — TypeScript типы
├── pages/
│   ├── HomePage.tsx      — Главная (выбор роли)
│   ├── HostPage.tsx      — Хост (управление игрой)
│   ├── PlayerPage.tsx    — Игрок (карточка лото)
│   └── GitHubGuidePage.tsx — Инструкция по GitHub
├── components/
│   └── LottoCard.tsx     — Компонент карточки лото
├── hooks/
│   └── usePeer.ts        — PeerJS хуки для связи
└── utils/
    └── gameUtils.ts      — Утилиты (генерация карточек и т.д.)
```

## 🔒 Приватность

- Вся музыка хранится локально в браузере
- PeerJS использует публичный signaling сервер для установки P2P соединения
- После установки соединения данные передаются напрямую между устройствами
